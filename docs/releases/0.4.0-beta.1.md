The first beta of Flyby 0.4: a Siri-style redesign, chats you can pick up again, and an on-device provider.

### What's new

- **Looks like macOS 27's Siri.** A dark glass bar at the bottom of the screen that grows up into an answer card when you hit Return, always dark, in Liquid Glass. The dropdown at the end of the bar ("Google ⌄") picks who answers; ⌘1–⌘4 and ⌘K work too.
- **Follow-ups and Recent Chats.** Once an answer is up, keep typing to ask a follow-up in the same conversation. Gemini and Apple Intelligence answer with the conversation so far; Google AI Mode answers each question on its own. Chats are kept on your Mac only, never uploaded: ⌘Y, ↑ in an empty bar or the Recent Chats pill reopens one, ⌘N starts a new chat, and Settings › History clears them.
- **Apple Intelligence.** A fourth provider, running on Apple's on-device model: no key, no account, and your question never leaves your Mac. It has no live web access, so for anything recent it points you to Gemini or AI Mode. Needs Apple Intelligence turned on in System Settings.
- **Keyboard map and "/" commands.** ⌘/ (or the Shortcuts pill) shows every shortcut. Type "/" at the start of the bar for commands: /settings, /history, /new, /google, /gemini, /apple, /browser and more.
- **New onboarding and Settings.** A short walkthrough with a live demo of the bar and a practice step for your shortcut. Settings is rebuilt in the shape of macOS 27's System Settings, with its own Shortcut and History panes.

### Requirements

macOS 27 on Apple silicon. Flyby 0.3 and earlier still run from macOS 14.

### Install

```sh
curl -fsSL https://raw.githubusercontent.com/emonsaqibh/flyby/main/install.sh | bash -s -- --beta
```

Already on 0.3 with macOS 27? The same command updates it. It's also what **Check for Updates…** hands you.

**Still on an older macOS with 0.3?** If you turned on beta updates, 0.3 may show "Update Available" for this version. The installer won't install it on a Mac that can't run it, so you can ignore the notice and keep using 0.3.

### Good to know

- Ad-hoc signed and not notarized, like 0.3: install with the command above rather than downloading the zip in a browser.
