Simpler shortcuts: key combos only, and no keyboard permissions.

### Changed

- **Flyby opens with ⌥/ by default.** Shortcuts are now key combos: a key pressed with modifiers, like ⌥/ or ⌃⌥Space. macOS delivers those with no permissions at all.
- **Double-tap and held-modifier shortcuts are gone.** On macOS 27 they needed both Accessibility and Input Monitoring, which updates kept taking away. If you had one, Flyby switches you to ⌥/ and tells you once. Record any combo you like in Settings › Shortcut.
- **Flyby no longer asks for Accessibility or Input Monitoring.** You can remove Flyby from both lists in System Settings › Privacy & Security.
- **Screenshots stay on ⌥⇧Space** by default. If yours was a double-tap, it's back to ⌥⇧Space.

### Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/emonsaqibh/flyby/main/install.sh | bash
```

Already on 0.5? Use **Check for Updates…** in the menu bar (or Settings › General › Updates); it hands you the same command.

Needs macOS 27 on Apple silicon. Not notarized: install with the command above rather than downloading the zip in a browser.
