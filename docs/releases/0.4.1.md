A fix for Google AI Mode follow-ups. Recommended for everyone who uses Google AI Mode.

### Fixed

- **AI Mode follow-ups keep the conversation.** In 0.4.0 every follow-up started a new Google chat, so Google lost what you'd been talking about: "what is its AnTuTu score?" after "iPhone 16 Pro performance" got an explanation of AnTuTu. Follow-ups now go into Google's own conversation on the page Flyby already has open, so Google answers them in context.
- **Chats reopened from Recent Chats carry on too.** When there's no open page to continue (a chat reopened from Recent Chats, after quitting Flyby, or after another provider answered part of the chat), Flyby asks Google a new question that includes your earlier questions and a short summary of the last answer.

### Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/emonsaqibh/flyby/main/install.sh | bash
```

Already on 0.4.0? Use **Check for Updates…** in the menu bar (or Settings › General › Updates); it hands you the same command.

Needs macOS 27 on Apple silicon. Ad-hoc signed and not notarized: install with the command above rather than downloading the zip in a browser.
