A smoother first run: setup comes first, picks up where you left off, and teaches both shortcuts for real.

### Changed

- **Setup comes first.** Until the walkthrough is done, the shortcuts, the menu bar and reopening Flyby all lead back to it, on the step you were on. Settings appears once you're set up.
- **It resumes where you left off.** Close the window or quit — or let macOS "Quit & Reopen" Flyby after you allow Screen Recording — and the walkthrough comes back on the same step, in front of your other windows.
- **Learn it by doing.** Press ⌥/ and the real bar opens; press esc to put it away, and you've got it. The screenshot step does the same with ⌥⇧Space: the wave plays, the bar opens with the picture attached, and esc puts it away.
- **Screen Recording is settled during setup,** with a button to allow it and one to reopen Flyby so it takes effect — no surprise prompt at your first screenshot.
- **One step fewer.** The separate shortcut step is gone; "Use a different shortcut" is right there in the practice step, and opens by itself if ⌥/ is taken by another app.

### Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/emonsaqibh/flyby/main/install.sh | bash
```

Already on 0.6? Use **Check for Updates…** in the menu bar (or Settings › General › Updates); it hands you the same command.

Needs macOS 27 on Apple silicon. Not notarized: install with the command above rather than downloading the zip in a browser.
