A fix for custom screenshot shortcuts. Recommended for everyone on 0.5.0.

### Fixed

- **A screenshot shortcut that can't work now says so.** Double-taps and chords need Flyby turned on under both Accessibility and Input Monitoring. In 0.5.0 a custom screenshot shortcut like double-tap Right ⌥ could sit waiting for those permissions with no sign of it. Now Settings › Shortcut and the What's new screen show what's missing, right under the shortcut, with a button to the right place in System Settings. The menu bar warns too, as it does for the shortcut that opens Flyby.
- **If Flyby already looks turned on in System Settings but the shortcut still doesn't work**, remove Flyby from the list with the − button and add it again. Flyby is ad-hoc signed, so macOS treats every update as a new app, and the old entry no longer matches.

### Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/emonsaqibh/flyby/main/install.sh | bash
```

Already on 0.5.0? Use **Check for Updates…** in the menu bar (or Settings › General › Updates); it hands you the same command.

Needs macOS 27 on Apple silicon. Ad-hoc signed and not notarized: install with the command above rather than downloading the zip in a browser.
