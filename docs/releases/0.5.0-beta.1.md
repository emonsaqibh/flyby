The first beta of Flyby 0.5: ask about what's on your screen.

### What's new

- **Ask about your screen.** Press **⌥⇧Space** from any app, click **Screenshot** under the bar, or type **/screenshot**. Flyby takes a picture of the window you're in while a wave of light crosses the screen from the bar, then opens with the picture waiting over the input. Ask anything about it, like "what does this error mean?" or "summarise this page", and Google AI Mode or Gemini answers. Return with nothing typed asks what's in it. Follow-ups can bring a new screenshot too.
- **Just the window, and only when you ask.** Flyby captures the window you were in, not the whole screen. Nothing leaves your Mac until you press Return, and ✕ takes the picture off.
- **Thumbnails in Recent Chats.** A chat keeps a small thumbnail of each screenshot, on your Mac only, and shows it over the question it went with.
- **Your shortcut, or none.** Settings › Shortcut has the screenshot shortcut too: record a different one, or turn it off.

### Fixed

- **Double-tap and chord shortcuts work on macOS 27.** On macOS 27 these gestures need Input Monitoring as well as Accessibility. Without it they stopped working without saying so, including the default, double-tap Right ⌥. Flyby now asks for both, and onboarding and the menu bar say which one is missing.

### Good to know

- **Screen Recording permission.** macOS asks the first time you take a screenshot. Flyby is ad-hoc signed, so macOS treats every update as a new app and forgets this permission (and Accessibility and Input Monitoring). When that happens, Flyby tells you how to fix it: remove Flyby from the list in System Settings with the − button, then add it again.
- **Google or Gemini, not Apple Intelligence.** The on-device model can't see pictures, so the Screenshot button hides while Apple Intelligence is selected.
- **Google AI Mode takes the picture through Google's own page**, the way pasting an image into it would. If Google changes that page it may stop working. Gemini is the steadier path for screenshots.

### Install

```sh
curl -fsSL https://raw.githubusercontent.com/emonsaqibh/flyby/main/install.sh | bash -s -- --beta
```

Already on 0.4 and on the beta channel? **Check for Updates…** hands you the same command.

Needs macOS 27 on Apple silicon. Ad-hoc signed and not notarized: install with the command above rather than downloading the zip in a browser.
