Permissions that survive updates. Recommended for everyone.

### Fixed

- **Updates no longer take Flyby's permissions away.** Up to 0.5.1 every Flyby build was signed differently, so macOS saw each update as a new app. Screen Recording, Accessibility and Input Monitoring stopped working while their switches still looked on in System Settings. From 0.5.2 Flyby is signed with the same certificate every time, so the permissions you give it now stay through future updates.
- **Flyby asks macOS again when a permission is missing**, instead of only showing a note, and the notes now say what's really going on.

### One last time

Because this is the change, 0.5.2 itself is still new to macOS. After updating, if screenshots or a double-tap shortcut don't work, go to System Settings › Privacy & Security. In **Screen & System Audio Recording**, and in **Accessibility** and **Input Monitoring** if you use a double-tap or chord, remove Flyby with the − button, then add it again or let Flyby ask. After that, updates keep them. If you use Gemini, macOS may also ask once more to let Flyby read its key from your keychain: choose Always Allow.

### Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/emonsaqibh/flyby/main/install.sh | bash
```

Already on 0.5? Use **Check for Updates…** in the menu bar (or Settings › General › Updates); it hands you the same command.

Needs macOS 27 on Apple silicon. Not notarized: install with the command above rather than downloading the zip in a browser.
